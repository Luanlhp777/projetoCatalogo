Trabalho em dupla ou individual

Nesta atividade vocês deverão continuar o Projeto Integrador — Catálogo de Produtos, desenvolvendo novas funcionalidades no Front-end e no Back-end.

Antes de começar
Leia o artigo e revise o projeto desenvolvido nas aulas:


https://desvendandoocodigo.com.br/?p=2315


O artigo contém as explicações do Front-end com React, do Back-end com Node.js e Express, as aulas em vídeo e o código utilizado como referência, além das aulas praticadas na sala de aula.

PROGRAMAÇÃO WEB II + DESENVOLVIMENTO DE SISTEMAS I
Foco: Front-end + Back-end

Trabalhar com o projeto completo:

Programação Web II: Front-end com React;

Desenvolvimento de Sistemas I: Back-end com Node.js e Express;

Integração: comunicação entre Front-end e Back-end através da API REST.

Evolução do Front-end

1. Contador de produtos
Exibir a quantidade de produtos cadastrados.
Atualizar o contador automaticamente quando a lista mudar.

2. Validação do formulário
Não permitir cadastro sem nome.
Não permitir preço igual ou menor que zero.
Exibir uma mensagem adequada ao usuário.

3. Busca de produtos
Criar um campo de busca.
Filtrar os produtos pelo nome.

4. Footer e CSS
Criar um componente Footer.

Melhorar a estilização da aplicação.

Manter a interface organizada e responsiva.

 Evolução do Back-end
Além das alterações no Front-end, vocês deverão continuar a evolução da API com Node.js e Express, implementando as novas funcionalidades propostas durante as aulas de Desenvolvimento de Sistemas I.

As alterações deverão manter a organização do projeto utilizando rotas, Controller e API REST.

 Entrega
O projeto deverá estar funcionando e integrado, com o React se comunicando corretamente com o Back-end.

As funcionalidades desenvolvidas deverão ser demonstradas em sala.

Não é necessário entregar PDF ou relatório.

O objetivo é compreender o funcionamento das duas partes da aplicação e conseguir evoluir o Projeto Integrador mantendo a integração entre Front-end e Back-end.
